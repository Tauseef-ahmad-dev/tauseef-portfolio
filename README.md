## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Google Fonts loads over the internet; the site has no build step or backend.

## Personalize before publishing
- **Profile photo:** Upload your preferred photo and name it `profile-photo.jpg`. In `index.html`, replace the `<div class="profile-placeholder">...</div>` inside `.profile-frame` with:
  `<img class="profile-photo" src="profile-photo.jpg" alt="Tauseef Ahmad">`
  Then add `.profile-photo { width:100%; height:100%; object-fit:cover; border-radius:5px; }` to `styles.css`. Or send the photo to ChatGPT and ask to integrate it.
- Add your CV PDF and link it from the hero buttons if you want a downloadable resume.
- Review project descriptions and ensure they accurately reflect your work and what you are allowed to share publicly.
- Add verified dates, measurable achievements, and project links only where accurate.

## Files
- `index.html` — page content and contact links
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation and dynamic footer year

## Deploy to GitHub Pages
Create a **public** repository named `tauseef-portfolio` under `Tauseef-ahmad-dev`, upload the four files (`index.html`, `styles.css`, `script.js`, `README.md`) to the repository root, then go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, and save. GitHub will publish the site at a URL similar to `https://tauseef-ahmad-dev.github.io/tauseef-portfolio/` after deployment finishes.

If you create the repository and share its URL, I can help add/update the files using the connected GitHub integration.
